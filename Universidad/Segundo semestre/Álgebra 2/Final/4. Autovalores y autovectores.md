# Definiciones
### Autovector:
Un autovector es un vector no nulo $\vec{v}$ que, al aplicarle una matriz cuadrada $A$ (o una aplicación lineal $T$), no cambia de dirección; solo se estira, se encoge o cambia de sentido. Cumple la siguiente ecuación:
$$\boxed{A\vec{v}=\lambda \vec{v}}$$
### Autovalor:
Es un escalar $\lambda\in \mathbb{R}$ que indica cuánto se escala el autovector $\vec{v}$ cuando se le aplica la matriz $A$. Es decir, es el número que verifica la ecuación:
$$\boxed{A\vec{v}=\lambda \vec{v}}$$
- Si $\lambda>1$, el autovector se alarga.
- Si $0<\lambda<1$, el autovector se acorta.
- Si $\lambda<0$, el autovector cambia de sentido. Su longitud depende de $|\lambda|$.
- Si $\lambda=0$, el resultado es el vector nulo.
> *Toda matriz de $n\times n$ tiene exactamente $n$ autovalores.*
### Autoespacio:
Un autoespacio $E_{\lambda}$ es el subespacio formado por todos los autovectores asociados a un mismo autovalor $\lambda$, junto con el vector nulo.

# Teoremas
### Teorema de los autovalores (ecuación característica):
**Enunciado:** sea $A$ una matriz cuadrada $n\times n$. Un escalar $\lambda$ es un autovalor de $A$ si y sólo si
$$\boxed{\det(A-\lambda I)=0}$$
Esta igualdad se denomina ecuación característica.
**Demostración:** partimos de la definición:
$$A\vec{v}=\lambda \vec{v}$$
Pasamos todo al mismo miembro:
$$A\vec{v}-\lambda I \vec{v}=0$$
Sacamos factor común:
$$(A-\lambda I)\vec{v}=0$$
Para que exista un autovector, necesitamos que exista una solución distinta del vector nulo.
Un sistema homogéneo tiene soluciones no triviales si y solo si su matriz tiene determinante igual a cero.
Por eso:
$$\boxed{\det(A-\lambda I)=0}$$
QED.
