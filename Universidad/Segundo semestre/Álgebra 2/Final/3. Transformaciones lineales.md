# Definiciones
### Aplicación lineal:
Una aplicación lineal $T$ es una **función** entre dos espacios vectoriales reales que asigna a cada vector del espacio de partida un único vector del espacio de llegada, conservando la suma y el producto por escalares.
1. Conserva la suma:
$$T(\vec{u}+\vec{v})=T(\vec{u})+T(\vec{v})$$
2. Conserva el producto por escalares:
$$T(\alpha \vec{v})=\alpha T(\vec{v})$$
