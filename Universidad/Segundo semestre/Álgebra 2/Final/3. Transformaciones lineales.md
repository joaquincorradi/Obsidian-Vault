# Definiciones
### Aplicación lineal:
Una aplicación lineal $T$ es una **función** entre dos espacios vectoriales reales que **asigna** a cada vector del espacio de partida $V$ un único vector del espacio de llegada $W$, **conservando** la suma y el producto por escalares, y se denota $T:V\to W$.
1. Conserva la suma:
$$T(\vec{u}+\vec{v})=T(\vec{u})+T(\vec{v})$$
2. Conserva el producto por escalares:
$$T(\alpha \vec{v})=\alpha T(\vec{v})$$
### Núcleo:
El núcleo de una aplicación lineal $T$ es el **conjunto** de todos los vectores del espacio de partida $V$ cuya imagen mediante $T$ es el **vector nulo** del espacio de llegada $W$:
$$\operatorname{ker}(T)=\{ \vec{v}\in V | T(\vec{v})=0 \}$$
#### Nulidad:
La nulidad de una aplicación lineal $T$ está dada por la dimensión del núcleo de $T$:
$$\operatorname{Nul}(T)=\operatorname{dim}(\operatorname{ker}(T))$$

### Imagen:
La imagen de una aplicación lineal $T$ es el **conjunto** de todos los vectores del espacio de llegada $W$ que **se obtienen al aplicar** $T$ a los vectores del espacio de partida $V$:
$$\operatorname{Im}(T)=\{ \vec{w}\in W|\vec{w} = T(\vec{v})\ \text{para alguna}\ \vec{v}\in V\}$$
#### Rango:
El rango de una aplicación lineal $T$ está dada por la dimensión de la imagen de $T$:
$$\operatorname{rg}(T)=\operatorname{dim}({\operatorname{Im}(T)})$$
> *Tanto el núcleo como la imagen de una aplicación lineal son subespacios vectoriales.*
### Matriz de transformación (matriz asociada / representación matricial):
Una aplicación lineal $T:\mathbb{R}^n\to\mathbb{R}^m$ puede expresarse mediante una matriz **única** de $m\times n$ llamada $A_{T}$, tal que al multiplicarla por cualquier vector del espacio de partida obtenemos su imagen:
$$T(\vec{v})=A_{T}\cdot \vec{v}$$
para todo $\vec{v}\in \mathbb{R}^n$.
La matriz $A_{T}$ se llama **matriz de transformación** de $T$.
De forma general para bases cualesquiera: sean $T:V\to W$, $B$ una base de $V$ y $B'$ una base de $W$:
$$[T(\vec{v})]_{B'}=A_{T}\cdot [\vec{v}]_{B}$$
### Aplicación inyectiva:
Una aplicación lineal es inyectiva si
$$T(\vec{v_{1}})=T(\vec{v_{2}})\implies \vec{v_{1}}=\vec{v_{2}}$$
> *$T$ es inyectiva si y sólo si $\operatorname{ker}(T)={\vec{0}}$.*
### Aplicación suryectiva:
Una aplicación lineal es suryectiva si
$$\forall \vec{w}\in W,\; \exists \vec{v}\in V|T(\vec{v})=\vec{w}$$
