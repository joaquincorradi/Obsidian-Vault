### Longitud de un vector:
La longitud o módulo de un vector $\vec{v}$ **es una medida** que indica **la distancia entre el origen de coordenadas y el extremo del vector**. Se representa mediante $\left\| \vec{v} \right\|$.
Si tenemos un vector de $\mathbb{R}^n$:
$$\vec{v}=(v_{1},v_{2},\dots,v_{n})$$
su longitud se calcula como:
$$\boxed{\left\| \vec{v} \right\|=\sqrt{ v_{1}^2+v_{2}^2+\cdots +v_{n}^2}}$$
> - La longitud siempre es mayor o igual a cero: $\left\| \vec{v} \right\| \geqslant 0$
> - Es cero si y solo si el vector es nulo: $\left\| \vec{v} \right\|=0\iff \vec{v}=\vec{0}$
### Producto punto
El producto punto de dos vectores $\vec{u}$ y $\vec{v}$, se define por:
$$\boxed{\vec{u}\cdot \vec{v}=\left\|\vec{u}\right\|\left\|\vec{v}\right\|\cos(\theta)}$$
donde $\theta$ es el ángulo entre ambos vectores. El resultado es un **número real**.
### Distancia entre dos puntos:
Dado dos puntos $P$ y $Q$, la distancia entre ellos es:
$$\operatorname{d}(P,Q)=\left\| \overrightarrow{PQ} \right\|=\left\| B-A \right\|$$
### Ángulo entre vectores:
Dados dos vectores no nulos $\vec{u}$ y $\vec{v}$, el ángulo $\theta$ entre ellos se calcula mediante el producto punto:
$$
\begin{align}
\cos(\theta)&=\frac{\vec{u}\cdot \vec{v}}{\left\| \vec{u} \right\|\cdot\left\| \vec{v} \right\|} \\
\theta&=\arccos \left( \frac{\vec{u}\cdot \vec{v}}{\left\| \vec{u} \right\|\cdot\left\| \vec{v} \right\|} \right)
\end{align}
$$
